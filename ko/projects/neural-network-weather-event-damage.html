프로젝트 16 · 머신러닝

신경망 · 기상 현상으로 인한 피해

⚠️ 진행 중데이터:2025

NOAA Storm Events 자료에 분류 모델을 적용해 기상 현상으로 경제적 피해가 기록될 확률을 추정합니다. 2010~2025년 데이터로 로지스틱 회귀와 신경망을 비교하고 훈련 기간 이후의 자료로 성능을 평가합니다.

배경과 목표

2010~2025년 NOAA Storm Events에 기록된 기상 현상 1,037,691건을 사용했습니다. 각 기록에는 현상, 날짜, 위치, 기상 특성과 보고된 경우 재산 및 농작물 피해액이 포함됩니다.

경제적 피해가 기록된 사건을 구별하는 목표 변수를 정의했습니다. 각 사건의 시간, 지역, 기상 특성으로 피해가 기록될 확률을 추정합니다. 피해액이나 정답을 직접 드러내는 다른 변수는 예측 변수에서 제외했습니다.

지도 학습 분류 모델 두 가지를 비교했습니다. 로지스틱 회귀는 변수별 계수로 통계적 기준을 제공하고 신경망은 변수 간 관계를 더 유연하게 학습합니다. 2010~2021년 자료로 훈련하고 2022·2023년으로 검증한 뒤 2024·2025년 사건으로 최종 평가했습니다. 이 시기별 분할로 학습 때보다 최근 기록에서의 성능을 확인합니다.

모델 및 검증

데이터 준비와 기록된 피해의 정의

NOAA Storm Events의 연도별 파일을 받아 한 데이터 세트로 통합했습니다. 모델 변수를 준비하기 전에 열 이름과 자료형, 결측치, 연도 간 일관성을 확인했습니다.

파일마다 재산 및 농작물 피해액이 천 단위나 백만 단위 등으로 다르게 표시됩니다. 비교 가능한 숫자로 변환한 뒤 합산해 각 사건의 경제적 피해 기록 여부를 나타내는 변수를 만들었습니다.

목표 변수 · 기록된 경제적 피해
y_i=\mathbb{1}\left(D_{\text{재산},i}+D_{\text{농작물},i}>0\right)

기록된 재산 피해와 농업 피해의 합이 0보다 크면 지표는 1, 나머지는 0입니다. 금액이 보고되지 않은 경우는 0으로 처리했습니다. 따라서 모델이 찾는 것은 NOAA에 기록된 피해이며 실제로 발생한 모든 피해를 포괄하지는 않습니다.

예측에는 원본 변수 19개(수치형 10개, 범주형 9개)를 사용했습니다. 날짜, 위치, 사건 유형, 규모와 좌표 등이 포함됩니다. 결측 표시 변수도 만들었습니다. 피해액과 결과를 직접 드러내는 열은 예측에서 제외해 사건 자체의 특성으로 학습하도록 했습니다.

시기별 데이터 분할과 변수 전처리

기록을 시간순으로 분할해 2010~2021년은 훈련, 2022~2023년은 검증, 2024~2025년은 최종 테스트에 사용했습니다. 첫 기간으로 모델을 추정하고 두 번째 기간으로 개발 중 성능을 추적한 뒤, 나중 시기의 데이터로 최종 비교했습니다.

두 모델을 훈련하기 전에 같은 전처리를 적용했습니다. 수치 변수의 결측치는 훈련 데이터의 중앙값으로 채우고 변수를 표준화해 척도를 맞췄습니다. 범주형 변수는 관측된 범주별로 표시 열을 만드는 원-핫 인코딩으로 변환했습니다. 전처리 기준은 훈련 데이터에서만 구한 뒤 검증 및 테스트 데이터에 그대로 적용했습니다.

기준 모델로 사용한 로지스틱 회귀

로지스틱 회귀를 기준 모델로 사용했습니다. 전처리한 변수마다 계수를 학습하고 그 기여도를 합쳐 피해가 기록될 가능성을 점수로 나타냅니다. 다른 변수가 같을 때 계수의 부호는 해당 변수가 점수를 높이는지 낮추는지 보여 주며, 크기는 모델 척도에서 기여의 정도를 나타냅니다. 시그모이드 함수가 이 점수를 0~1 사이의 확률로 변환합니다.

로지스틱 회귀로 추정한 확률
\hat{p}_i=\frac{1}{1+e^{-(\beta_0+\sum_j\beta_jx_{ij})}}

식의 x는 전처리한 변수, β는 훈련 데이터로 추정한 계수입니다. 시그모이드 함수는 선형 조합을 0과 1 사이의 경제적 피해 기록 확률로 변환합니다.

훈련에는 L2 정규화를 적용해 지나치게 큰 계수를 억제하고 변환된 변수가 많을 때도 추정이 안정적이도록 합니다. 로지스틱 회귀를 기준으로 같은 기간의 신경망과 확률, 정답, 오답을 비교해 신경망의 유연성이 얼마나 도움이 되는지 확인합니다.

신경망과 결과 비교

전처리가 끝난 동일한 변수로 완전연결층 신경망을 훈련했습니다. 로지스틱 회귀와 달리 신경망은 학습한 가중치로 여러 단계에 걸쳐 신호를 결합합니다. ReLU 활성화 함수로 비선형 관계를 포착하고 드롭아웃으로 과적합을 줄입니다. 마지막 층의 시그모이드 함수는 피해가 기록될 확률을 출력합니다.

은닉층에서의 변환
h^{(l)}=\mathrm{ReLU}\left(W^{(l)}h^{(l-1)}+b^{(l)}\right)

각 층에서 가중치 W와 편향 b가 입력 정보를 변환합니다. ReLU 함수를 사용하면 단순한 선형 조합으로 표현할 수 없는 관계도 학습할 수 있습니다.

신경망이 추정한 확률
\hat{p}_i=\sigma\left(w^\top h_i+b\right)

마지막 층은 신경망이 학습한 정보에 시그모이드 함수 σ를 적용해 각 사건에서 피해가 기록될 확률을 출력합니다.

모델 오차에 따라 가중치를 조정하는 Adam으로 신경망을 훈련했습니다. 이진 교차 엔트로피로 예측 확률과 관측 결과의 차이를 측정했습니다. 검증 결과에 따라 학습률을 조정하고 성능이 향상되지 않으면 훈련을 중단해 과적합을 줄였습니다.

손실 함수 · 이진 교차 엔트로피
\mathcal{L}=-\frac{1}{n}\sum_{i=1}^{n}\left[y_i\log(\hat{p}_i)+(1-y_i)\log(1-\hat{p}_i)\right]

교차 엔트로피는 관측 결과 y와 추정 확률 p̂를 비교합니다. 값이 작을수록 예측 확률이 실제 결과에 더 잘 맞습니다.

ROC AUC와 PR AUC로 피해가 기록된 사건과 나머지를 구별하는 능력을 비교했습니다. 피해 사건이 드물어 PR AUC가 특히 중요합니다. 정밀도, 재현율, F1과 혼동 행렬로 실제 양성을 얼마나 탐지하고 경보 중 몇 건이 정확했는지도 확인했습니다.

피해 사건 탐지의 정밀도와 재현율
\mathrm{Precision}=\frac{VP}{VP+FP}
\mathrm{Recall}=\frac{VP}{VP+FN}

VP는 모델이 정확히 탐지한 피해 사건, FP는 피해 기록이 없지만 경보가 나온 사건, FN은 탐지하지 못한 피해 사건입니다. 정밀도는 양성 경보 중 맞은 비율을, 재현율은 실제 피해 사건 중 탐지한 비율을 나타냅니다.

결과물과 배운 점

2024~2025년 사건을 이용한 최종 테스트에서 신경망은 ROC AUC 0.9324, PR AUC 0.8004를 기록했고 로지스틱 회귀는 각각 0.8961, 0.6691이었습니다. 신경망이 피해가 기록된 사건을 더 잘 구분했으며 특히 PR AUC에서 차이가 뚜렷했습니다.

피해가 기록된 사건에 대해 신경망은 정밀도 0.7942, 재현율 0.6243, F1 점수 0.6991을 기록했습니다. 로지스틱 회귀는 각각 0.7580, 0.5023, 0.6042였습니다. 신경망은 실제 피해 사건을 더 많이 찾아내면서, 피해로 예측한 사건 중 실제 피해의 비율도 더 높았습니다.

F1 점수 · 정밀도와 재현율의 균형
F_1=2\,\frac{\mathrm{Precision}\cdot\mathrm{Recall}}{\mathrm{Precision}+\mathrm{Recall}}

F1 점수는 정밀도와 재현율을 하나로 결합합니다. 양성 사례를 찾아내는 동시에 오경보를 줄이는 것이 중요할 때 모델 비교에 활용합니다.

사건별 확률, 두 모델의 예측, 혼동 행렬, 비교 지표와 학습 그래프를 제공합니다. 동일한 변수를 갖춘 새 기록에 적용하도록 전처리 절차와 모델을 보관했습니다. 이후 연도의 예측과 실제 피해 기록을 비교해 성능이 유지되는지, 재학습이 필요한지 판단할 수 있습니다.
