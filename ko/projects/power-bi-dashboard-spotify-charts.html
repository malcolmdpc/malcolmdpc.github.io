프로젝트 13 · Power BI 대시보드

Power BI 대시보드 · Spotify Charts

⚠️ 진행 중데이터: 2026

Spotify Charts의 곡, 아티스트, 앨범, 시장별 공개 자료를 분석했습니다. Power BI 대시보드에서 스트리밍 수, 차트 진입 현황, 시기별 1위 곡과 지역별 분포를 살펴볼 수 있습니다.

배경과 목표

Spotify Charts의 공개 자료로 곡, 아티스트, 앨범, 날짜, 시장 정보를 통합한 Power BI 대시보드를 만들고 차트별 음악 분포를 분석합니다.

스트리밍이 집중된 곡과 차트에 꾸준히 이름을 올리는 아티스트를 찾고, 시기별 1위 변화와 데이터에서 활동 비중이 큰 시장을 분석합니다.

모델 개발

  • Spotify Charts 공개 자료로 일간 곡 차트, 일간 아티스트 차트, 주간 앨범 차트를 분석합니다.
  • 곡, 아티스트, 앨범, 국가, 날짜, 시각화 보조 정보를 구분하고 팩트·차원 테이블과 관계를 정의해 Power BI 분석용 데이터 모델을 준비합니다.
  • 총 스트리밍 수, 차트 등장 횟수, 최고 순위, 상위 10위 진입, 시장별 차트 진입, 1위 곡의 집중도와 시간에 따른 순위 변화를 측정하는 지표를 만들었습니다.
  • 대화형 시각화와 기간, 국가, 시장 집단, 아티스트, 곡 필터로 음악 소비 패턴을 탐색합니다.

현재 상태와 다음 단계

데이터를 정리하고 관계형 모델을 구축한 뒤 Power BI로 시각화해 Spotify 음악 차트를 읽기 쉽게 구성했습니다.

어두운 테마의 포트폴리오용 대화형 대시보드를 목표로 합니다. 차트의 집중도와 선두 주자, 지역별 진입 현황과 시기별 변화를 그래프로 빠르게 파악할 수 있도록 구성합니다.
