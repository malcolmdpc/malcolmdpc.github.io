Project 01 · Data Analytics

Analyse van vluchten op de Balearen

✅ gepubliceerd data: 2025

Analyse van het luchtverkeer in Spanje met openbare data van AENA, gericht op verkeersvolumes, patronen per luchthaven en verschillen tussen categorieën.

CONTEXT EN DOEL

Verkennen hoe het luchtverkeer op de Balearen is verdeeld naar luchthaven, volume en type verkeer.

DATA EN EERSTE ANALYSE

  • Gebruik van openbare data van AENA als belangrijkste bron.
  • Vergelijking van luchthavens, categorieën en verkeersontwikkelingen.
  • Visualisaties ontwikkelen om operationele data te vertalen naar een geografisch inzicht.

OPLEVERING EN INZICHTEN

Het project is beschikbaar als reproduceerbare analyse op GitHub en als redactionele bijdrage op LinkedIn, met een visueel verhaal dat gericht is op patronen en context.

TECHNISCHE FICHE

Type analyse
Data Analytics · Visualisatie · Data storytelling
Databron
Openbare data van AENA
Onderzochte periode
2024 en 2025
Analyseeenheid
Luchtvaartpassagiers van en naar luchthavens op de Balearen
Gebied
Palma de Mallorca · Ibiza · Menorca
Belangrijkste variabelen
Passagiers, luchthavens, landen, steden, luchtvaartmaatschappijen, maanden en seizoen
Analytische invalshoek
Luchtvaartvraag, seizoenspatronen, internationale verbindingen en geografische verdeling van het verkeer op de Balearen
Toegepaste bewerkingen
Data opschonen, aggregatie in de tijd, vergelijking tussen seizoenen en analyse per luchthaven, land, stad en luchtvaartmaatschappij
Hulpmiddelen
Python · Pandas · Plotly · GitHub
Projectresultaat
Analytisch notebook, grafieken en publicatie op LinkedIn
Status
Gepubliceerd
