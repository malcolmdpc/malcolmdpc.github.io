Project 08 · Machine learning

Machinelearningmodel · Fraude met K-means

✅ gepubliceerd

Onbegeleide clustering met K-means voor het opsporen van creditcardfraude.

CONTEXT EN DOEL

Onderzoeken of een onbegeleide techniek transactiegedrag kan onderscheiden dat past bij fraudepatronen.

DATA EN EERSTE ANALYSE

  • Transactievariabelen gebruiken om gedragsgroepen te vormen.
  • K-means toepassen om waarnemingen te segmenteren zonder voorafgaande labels.
  • Clusterprofielen interpreteren om segmenten met afwijkende signalen te herkennen.

OPLEVERING EN INZICHTEN

Het resultaat vergelijkt een implementatie in SPSS Modeler met een Python-versie en toont de waarde van clustering als verkennend hulpmiddel bij fraude.

TECHNISCHE FICHE

Type analyse
Machine learning · Clustering · Fraudedetectie
Databron
Dataset met transacties
Analyseeenheid
Transacties in de fraudedataset
Belangrijkste variabelen
Bedrag, transactiegedrag, transactievariabelen, afgeleide variabelen en signalen van afwijkende patronen
Analytische invalshoek
Transacties segmenteren met K-means om gedragsgroepen en mogelijke fraudepatronen te herkennen
Toegepaste bewerkingen
Data voorbereiden, variabelen opschonen, schalen, onbegeleide segmentatie, clusteranalyse en profielinterpretatie
Hulpmiddelen
Python · Pandas · Scikit-learn · SPSS · GitHub
Projectresultaat
