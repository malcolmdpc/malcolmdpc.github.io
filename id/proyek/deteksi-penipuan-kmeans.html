Proyek 08 · Pembelajaran Mesin

Model Machine Learning · Deteksi Penipuan dengan K-means

✅ diterbitkan

Clustering tanpa supervisi dengan K-means untuk mendeteksi penipuan kartu kredit.

KONTEKS DAN TUJUAN

Mengeksplorasi apakah teknik tanpa supervisi dapat memisahkan perilaku transaksi yang sesuai dengan pola penipuan.

DATA DAN DIAGNOSA

  • Penggunaan variabel transaksional untuk membangun kelompok perilaku.
  • Penerapan K-means untuk mengelompokkan observasi tanpa menggunakan label sebelumnya.
  • Membaca profil cluster untuk mengidentifikasi segmen dengan sinyal atipikal.

HASIL DAN PEMBELAJARAN

Proyek ini membandingkan penerapan di SPSS Modeler dan Python untuk menunjukkan bagaimana analisis klaster membantu menelusuri kemungkinan pola penipuan.

LEMBAR TEKNIS

Tipe analisis
