项目 13 · Power BI 仪表板

Power BI 仪表板 · Spotify Charts 排行榜

⚠️ 开发中数据： 2026

使用歌曲、艺人、专辑和市场的公开数据分析 Spotify Charts 排行榜。通过 Power BI 交互式仪表板，探索播放量、上榜情况、不同时期的榜首变化及地域分布。

背景与目标

以 Spotify Charts 公开数据构建 Power BI 分析仪表板，整合歌曲、艺人、专辑、日期与市场信息，了解音乐在不同排行榜中的分布。

项目旨在找出播放量最集中的歌曲、长期上榜的艺人、不同时间领跑榜单的作品，以及数据中最活跃的市场。

模型开发

  • 以 Spotify Charts 公开数据为主要来源，分析歌曲日榜、艺人日榜和专辑周榜。
  • 在 Power BI 中使用事实表、维度表和关系构建分析模型，分别组织歌曲、艺人、专辑、国家、日期及辅助展示信息。
  • 构建指标，衡量总播放量、上榜次数、最高排名、进入前十的次数、各市场的上榜情况、榜首歌曲集中度和排名变化。
  • 通过交互式图表探索音乐消费规律，可按时段、国家、市场组别、艺人和歌曲筛选。

当前进展与下一步

目前已在 Power BI 中串联数据准备、关系建模与可视化，以清晰呈现 Spotify 音乐排行榜。

预期成果是用于作品集展示的深色交互式仪表板。它面向管理层概括要点，通过图表呈现榜单的集中度、领先者、地域覆盖和时间变化。

技术说明

分析类型
数据分析 · Power BI 仪表板 · 数据叙事
数据来源
Spotify Charts · 歌曲、艺人与专辑公开排行榜
分析时段
2026
分析单位
按日期和市场整理的歌曲、艺人、专辑和音乐排行榜记录
主要变量
播放量、排名、歌曲、艺人、专辑、国家、市场组别、日期、入榜状态、在榜天数、在榜周数和各市场上榜情况
分析方向
Spotify Charts 排行榜上榜情况、播放量集中度、榜首变化、地域分布，以及榜单中歌曲、艺人与专辑的比较
处理方法
数据准备、清洗数据表、建立关系模型、创建维度表和事实表、定义 DAX 度量值、验证关系，以及设计 Power BI 交互式可视化
工具
Power BI · DAX（Data Analysis Expressions，数据分析表达式）· Python · Pandas · GitHub
项目产出
Power BI 交互式仪表板、数据模型、分析度量值、探索性图表和 GitHub 上的流程文档
