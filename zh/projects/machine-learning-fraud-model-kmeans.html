项目 08 · 机器学习

机器学习模型 · 用 K-means 检测欺诈

✅ 已发布

使用 K-means 进行无监督聚类，检测信用卡欺诈。

背景与目标

探究无监督学习能否分辨出与欺诈模式相符的交易行为。

数据与诊断

  • 使用交易变量对行为相似的交易进行分组。
  • 用 K-means 在无预设标签的情况下对观测记录进行分群。
  • 解读各簇的特征，找出具有异常信号的群组。

交付与收获

比较 SPSS Modeler 与 Python 两种实现，说明聚类如何用于欺诈探索性分析。

技术说明

分析类型
机器学习 · 聚类 · 欺诈检测
数据来源
交易记录数据集
分析单位
欺诈数据集中的交易记录
主要变量
交易金额、交易行为、交易变量、衍生变量及与异常模式相关的信号
分析方向
使用 K-means 对交易分群，识别行为群组及潜在欺诈模式
处理方法
数据准备、变量清洗、缩放、无监督分群、聚类分析和群组特征解读
工具
Python · Pandas · Scikit-learn · SPSS · GitHub
项目产出
建模笔记本、图表、交易分群及 GitHub 文档
状态
已发布
