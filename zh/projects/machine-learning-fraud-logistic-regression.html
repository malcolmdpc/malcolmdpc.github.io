项目 09 · 机器学习

机器学习模型 · 用逻辑回归检测欺诈

✅ 已发布

对信用卡交易进行逻辑回归分析，估计欺诈概率。用已有分类的交易训练模型，识别与风险相关的信号并分析预测结果。

背景与目标

通过信用卡交易记录研究欺诈交易中较常见的特征。每笔交易包含描述交易的数据及正常或欺诈的已知标签，因此可以用有结果的样本训练模型，再应用于其他交易。

目标是估算每笔交易的欺诈概率，并找出影响估计的变量。逻辑回归既可对交易分类，又可解释各项特征与预测结果之间的关系。

模型与评估

数据准备

先检查交易数据的变量并整理模型输入。准备流程包括清洗、变量处理和类别平衡；当欺诈交易远少于正常购买时，类别平衡尤为重要。

整理后的数据用于训练和评估。所选变量描述交易特征，已知欺诈标签提供学习依据，帮助模型区分两类交易。

使用逻辑回归分类

逻辑回归结合各笔交易的特征，估算 0 至 1 之间的欺诈概率。模型在训练中为各变量拟合系数，再用逻辑函数将各项贡献的组合转换为交易的欺诈概率。

估算欺诈概率
p(x)=\frac{1}{1+e^{-(\beta_0+\sum_{j=1}^{k}\beta_jx_j)}}

p(x) 为估计的欺诈概率。x 表示交易特征，各 β 系数表示模型学到的相应变量贡献。

系数反映其他变量不变时各特征与估计概率的关系，据此可识别所分析交易中与风险上升或下降相关的信号。

预测评估

将预测与已知交易类别对照评估。比较估计概率和决策阈值，决定哪些交易发出疑似欺诈警报。阈值会影响发现的欺诈数量，也影响有多少正常购买需要人工核查。

交易分类阈值
\hat{y}=\begin{cases}1&\text{若}p(x)\geq t\\0&\text{若}p(x)<t\end{cases}

在该规则中，1 表示潜在欺诈警报，0 表示归为正常交易。t 为决策阈值，具体取值可根据评估标准选择。

项目在 SPSS Modeler 中完成建模，并提供 Python 实现。通过评估指标和图表，可以在两种工具中分别检验模型表现，分析与欺诈相关的信号。

交付与收获

项目展示用于信用卡交易的监督逻辑回归模型、变量准备、预测和评估结果。结合 SPSS Modeler 与 Python，可以查看整个流程及各变量对分类的贡献。

对具有相同变量的新交易生成估计，再与已确认结果对照，可检查模型是否仍具检测能力，并判断何时需要重新训练。
