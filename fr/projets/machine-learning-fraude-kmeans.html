Projet 08 · Machine Learning

Modèle de Machine Learning · Fraude avec K-means

✅ publié

Clustering non supervisé K-means appliqué à la détection de fraude par carte bancaire.

CONTEXTE ET OBJECTIF

Explorer si une technique non supervisée peut séparer des comportements transactionnels compatibles avec des schémas de fraude.

DONNÉES ET DIAGNOSTIC

  • Les variables transactionnelles sont utilisées pour construire des groupes de comportement.
  • K-means est appliqué pour segmenter les observations sans utiliser d’étiquette préalable.
  • Les profils des clusters sont analysés afin d’identifier les segments présentant des signaux atypiques.

LIVRABLE ET ENSEIGNEMENTS

Le livrable compare une implémentation dans SPSS Modeler et une version Python, montrant la valeur du clustering comme outil exploratoire pour la fraude.

FICHE TECHNIQUE

Type d’analyse
Machine Learning · Clustering · Détection de fraude
Source des données
Jeu de données d’opérations transactionnelles
Unité d’analyse
Opérations enregistrées dans le jeu de données de fraude
Variables principales
Montant, comportement de l’opération, variables transactionnelles, variables dérivées et signaux associés à des schémas atypiques
Axe d’analyse
Segmentation des opérations avec K-means pour identifier des groupes de comportement et de possibles schémas de fraude
Traitement appliqué
Préparation des données, nettoyage des variables, standardisation, segmentation non supervisée, analyse des clusters et interprétation des profils
Outils
Python · Pandas · Scikit-learn · SPSS · GitHub
Livrable du projet
Notebook de modélisation, graphiques, segmentation des opérations et documentation sur GitHub
