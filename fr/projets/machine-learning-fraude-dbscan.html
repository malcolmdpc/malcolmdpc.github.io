Projet 10 · Machine Learning

Modèle de Machine Learning · Fraude avec DBSCAN

✅ publié

Clustering non supervisé DBSCAN pour détecter de potentiels schémas de fraude par carte bancaire.

CONTEXTE ET OBJECTIF

Détecter des groupes denses et des observations atypiques pouvant servir de signaux exploratoires de fraude.

DONNÉES ET DIAGNOSTIC

  • DBSCAN est utilisé pour identifier les zones de densité et les points isolés sans prédéfinir le nombre de clusters.
  • Les schémas atypiques et la séparation des segments transactionnels sont évalués.
  • Le résultat est interprété comme un outil exploratoire et non comme un diagnostic définitif de fraude.

LIVRABLE ET ENSEIGNEMENTS

Le livrable documente une alternative non supervisée fondée sur la densité pour compléter d’autres approches de détection de fraude.

FICHE TECHNIQUE

Type d’analyse
Machine Learning · Clustering · Détection d’anomalies
Source des données
Jeu de données d’opérations transactionnelles
Unité d’analyse
Opérations enregistrées dans le jeu de données de fraude
Variables principales
Montant, comportement de l’opération, variables transactionnelles, variables dérivées et signaux associés aux opérations atypiques
Axe d’analyse
Identification de regroupements et d’opérations atypiques avec DBSCAN afin de détecter de possibles schémas de fraude
Traitement appliqué
Préparation des données, nettoyage des variables, standardisation, segmentation non supervisée, détection du bruit et analyse des groupes atypiques
Outils
Python · Pandas · Scikit-learn · GitHub
Livrable du projet
Notebook de modélisation, graphiques, détection d’opérations atypiques et documentation sur GitHub
