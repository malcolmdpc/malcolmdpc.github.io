Analyse des hébergements Airbnb à Londres

✅ publié données: 2025

Analyse exploratoire des hébergements Airbnb à Londres, centrée sur les prix, les catégories d’hébergement, les avis et les tendances territoriales.

CONTEXTE ET OBJECTIF

Quels schémas apparaissent dans l’offre Airbnb à Londres lorsque les prix, les types d’hébergement, les avis et la répartition territoriale sont analysés conjointement ?

DONNÉES ET DIAGNOSTIC

  • Les données publiques d’Inside Airbnb sont utilisées comme source principale.
  • Les annonces sont nettoyées, validées et segmentées afin de construire une base analytique cohérente.
  • Des visualisations sont construites pour comparer les prix, les catégories, les quartiers, la concentration territoriale et l’activité récente.

LIVRABLE ET ENSEIGNEMENTS

Le projet est présenté comme une analyse reproductible sur GitHub et un contenu éditorial sur LinkedIn, avec une lecture visuelle centrée sur les prix, la localisation et la structure de l’hébergement urbain.

FICHE TECHNIQUE

Type d’analyse
Analyse de données · Visualisation · Narration de données
Source des données
Inside Airbnb · Londres
Période analysée
Septembre 2025
Unité d’analyse
Hébergements Airbnb publiés à Londres
Variables principales
Prix, type de chambre, quartier, disponibilité, nombre minimum de nuits, avis, activité récente et concentration des hôtes
Axe d’analyse
Prix, disponibilité, segmentation territoriale et différences selon le type d’hébergement
Traitement appliqué
Nettoyage des données, filtres de qualité, analyse exploratoire et comparaison par segments
Outils
Python · Pandas · Plotly · GitHub
Livrable du projet
Notebook analytique, graphiques et documentation sur GitHub
