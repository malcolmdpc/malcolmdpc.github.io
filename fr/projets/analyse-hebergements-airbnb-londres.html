Projet 02 · Analyse de données

Analyse des hébergements Airbnb à Londres

✅ publié données: 2025

Analyse exploratoire d’Airbnb à Londres pour comparer les prix, les types d’hébergement, la disponibilité, les séjours minimums et les différences entre quartiers.

CONTEXTE ET OBJECTIF

Explorer les variations de prix des hébergements Airbnb à Londres selon le type d’hébergement, le quartier, la disponibilité et le séjour minimum.

DONNÉES ET DIAGNOSTIC

  • Les données publiques d’Inside Airbnb sont utilisées comme source principale.
  • Nettoyage et application de filtres de qualité sur le prix, les avis récents, le séjour minimum et la disponibilité afin de construire une base analytique cohérente.
  • Construction d’indicateurs et de visualisations pour comparer les prix par type d’hébergement, quartier, séjour minimum et disponibilité annuelle.

LIVRABLE ET ENSEIGNEMENTS

Le projet est présenté comme une analyse reproductible sur GitHub et comme un contenu éditorial sur LinkedIn, avec une lecture visuelle centrée sur la structure des prix et les différences entre segments du marché.

FICHE TECHNIQUE

Type d’analyse
Analyse de données · Visualisation · Narration de données
Source des données
Inside Airbnb · Londres
Période analysée
Septembre 2025
Unité d’analyse
Hébergements Airbnb publiés à Londres
Variables principales
Prix, type de chambre, quartier, disponibilité annuelle, nuits minimums, avis, activité récente et nombre d’annonces par hôte
Axe d’analyse
Prix et différences selon le type d’hébergement, le quartier, la disponibilité annuelle et le séjour minimum
Traitement appliqué
Nettoyage des données, filtres de qualité, analyse descriptive et comparaison par segments
Outils
Python · Pandas · Plotly · GitHub
Livrable du projet
Notebook analytique, graphiques et documentation sur GitHub
Statut
Publié
