Projet 04 · Machine Learning

Modèle de Machine Learning · Airbnb à Londres

✅ publiédonnées: 2025

Classification supervisée des hébergements selon une tendance de prix relativement élevée ou faible au sein de chaque type d’hébergement.

CONTEXTE ET OBJECTIF

Construire une lecture supervisée permettant de distinguer les hébergements relativement chers et bon marché en comparant les prix au sein de chaque type d’hébergement.

DONNÉES ET DIAGNOSTIC

  • La base Airbnb Londres préparée et nettoyée sert de point de départ.
  • Une étiquette relative par type d’hébergement est définie afin d’éviter de comparer directement des segments différents.
  • Le modèle est entraîné et interprété en mettant l’accent sur l’explicabilité, les signaux territoriaux et les variables opérationnelles.

LIVRABLE ET ENSEIGNEMENTS

Le livrable relie analyse exploratoire et modélisation, en montrant comment un score peut classer les hébergements selon leur tendance relative à un prix élevé sans devenir une prédiction directe du prix.

FICHE TECHNIQUE

Type d’analyse
Machine Learning · Classification · Analyse de données
Source des données
Inside Airbnb · Londres
Période analysée
Septembre 2025
Unité d’analyse
Hébergements Airbnb publiés à Londres
Variables principales
Prix, type de chambre, quartier, disponibilité, minimum de nuits, avis, activité récente, concentration des hôtes et variables dérivées
Axe d’analyse
Classification des hébergements selon leur tendance relative à des prix élevés ou faibles au sein de chaque type de chambre
Traitement appliqué
Nettoyage des données, filtres de qualité, préparation des variables, segmentation par type d’hébergement et entraînement de modèles supervisés
Outils
Python · Pandas · Scikit-learn · Plotly · GitHub
Livrable du projet
Notebook de modélisation, graphiques, métriques d’évaluation et documentation sur GitHub
