Projet 09 · Machine Learning

Modèle de Machine Learning · Fraude avec régression logistique

✅ publié

Modèle supervisé de régression logistique pour la détection de fraude par carte bancaire.

CONTEXTE ET OBJECTIF

Modéliser la probabilité de fraude à partir de variables transactionnelles et analyser les signaux qui contribuent le plus à la classification supervisée.

DONNÉES ET DIAGNOSTIC

  • Les variables sont préparées pour l’entraînement supervisé.
  • La régression logistique est utilisée comme modèle de référence interprétable.
  • Les performances, la classification et la contribution des variables sont analysées pour évaluer les signaux de fraude.

LIVRABLE ET ENSEIGNEMENTS

Le livrable présente le flux complet d’un modèle supervisé interprétable, avec une implémentation SPSS Modeler et un support comparatif en Python.

FICHE TECHNIQUE

Type d’analyse
Machine Learning · Classification · Détection de fraude
Source des données
Jeu de données d’opérations transactionnelles
Unité d’analyse
Opérations enregistrées dans le jeu de données de fraude
Variables principales
Montant, comportement de l’opération, variables transactionnelles, variables dérivées et signaux associés au risque de fraude
Axe d’analyse
Classification des opérations par régression logistique pour estimer la probabilité de fraude et interpréter les signaux de risque
Traitement appliqué
Préparation des données, nettoyage des variables, équilibrage des classes, entraînement supervisé, évaluation des métriques et interprétation du modèle
Outils
Python · Pandas · Scikit-learn · SPSS · GitHub
Livrable du projet
Notebook de modélisation, graphiques, métriques de classification et documentation sur GitHub
