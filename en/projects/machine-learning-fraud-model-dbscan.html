Project 10 · Machine learning

Machine Learning Model · Fraud with DBSCAN

✅ published

Unsupervised DBSCAN clustering to detect potential credit card fraud patterns.

CONTEXT AND OBJECTIVE

Detect dense groups and atypical observations that may work as exploratory fraud signals.

DATA AND DIAGNOSIS

  • DBSCAN is used to identify densities and isolated points without predefining the number of clusters.
  • Atypical patterns and transactional segment separation are evaluated.
  • The result is read as an exploratory tool, not as a definitive fraud diagnosis.

DELIVERY AND LEARNING

The delivery documents a density-based unsupervised alternative to complement other fraud detection approaches.

TECHNICAL SHEET

Analysis type
Machine Learning · Clustering · Anomaly detection
Data source
Transactional operations dataset
Unit of analysis
Operations recorded in the fraud dataset
Main variables
Amount, operation behavior, transactional variables, derived variables and signals associated with atypical operations
Analysis axis
Identification of groupings and atypical operations using DBSCAN to detect possible fraud patterns
Treatment applied
Data preparation, variable cleaning, scaling, unsupervised segmentation, noise detection and analysis of atypical groups
Tools
Python · Pandas · Scikit-learn · GitHub
Project output
Modeling notebook, charts, detection of atypical operations and documentation on GitHub
