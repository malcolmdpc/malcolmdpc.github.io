Project 01 · Data analytics

Balearic Islands Flight Analysis

✅ published data: 2025

Analysis of air traffic in Spain using public AENA data, focused on volume, airport-level patterns and differences across traffic categories.

CONTEXT AND OBJECTIVE

What patterns appear in Balearic Islands air traffic when the data is read by airport, volume and traffic type?

DATA AND DIAGNOSIS

  • Public AENA data is used as the main source.
  • Airports, categories and traffic variations are compared.
  • Visuals are built to turn operational data into a territorial reading.

DELIVERY AND LEARNING

The project is presented as a reproducible analysis on GitHub and as an editorial piece on LinkedIn, with a visual narrative focused on patterns and context.

TECHNICAL SHEET

Analysis type
Data analytics · Visualization · Data storytelling
Data source
Public AENA data
Period analyzed
2024 and 2025
Unit of analysis
Air passengers linked to Balearic Islands airports
Territory
Palma de Mallorca · Ibiza · Menorca
Main variables
Passengers, airports, countries, cities, airlines, months and season
Analysis axis
Air demand, seasonality, international connectivity and territorial distribution of traffic in the Balearic Islands
Treatment applied
Data cleaning, temporal aggregation, comparison between seasons, analysis by airports, countries, cities and airlines
Tools
Python · Pandas · Plotly · GitHub
Project output
Analytical notebook, charts and LinkedIn publication
