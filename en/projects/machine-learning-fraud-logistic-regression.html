Project 09 · Machine learning

Machine Learning Model · Fraud with Logistic Regression

✅ published

Supervised logistic regression model for credit card fraud detection.

CONTEXT AND OBJECTIVE

Model fraud probability from transactional variables and review which signals contribute most to supervised classification.

DATA AND DIAGNOSIS

  • Variables are prepared for supervised training.
  • Logistic regression is applied as an interpretable baseline.
  • Performance, classification and variable contribution are read to evaluate fraud signals.

DELIVERY AND LEARNING

The delivery shows the full flow of an interpretable supervised model, with an SPSS Modeler implementation and comparative Python support.

TECHNICAL SHEET

Analysis type
Machine Learning · Classification · Fraud detection
Data source
Transactional operations dataset
Unit of analysis
Operations recorded in the fraud dataset
Main variables
Amount, operation behavior, transactional variables, derived variables and signals associated with fraud risk
Analysis axis
Classification of operations using logistic regression to estimate fraud probability and interpret risk signals
Treatment applied
Data preparation, variable cleaning, class balancing, supervised training, metric evaluation and model interpretation
Tools
Python · Pandas · Scikit-learn · SPSS · GitHub
Project output
Modeling notebook, charts, classification metrics and documentation on GitHub
