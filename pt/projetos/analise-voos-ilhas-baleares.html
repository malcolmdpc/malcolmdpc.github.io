Projeto 01 · Análise de dados

Análise de Voos nas Ilhas Baleares

✅ publicado dados: 2025

Análise do tráfego aéreo em Espanha com dados públicos da AENA, focada em volumes, padrões por aeroporto e diferenças entre categorias.

CONTEXTO E OBJETIVO

Explorar como se distribui o tráfego aéreo nas Ilhas Baleares por aeroporto, volume e tipo de tráfego.

DADOS E DIAGNÓSTICO

  • Utilização de dados públicos da AENA como fonte principal.
  • Comparação entre aeroportos, categorias e variações de tráfego.
  • Construção de visuais para transformar dados operacionais numa leitura territorial.

ENTREGA E APRENDIZAGEM

O projeto é apresentado como uma análise reproduzível no GitHub e como peça editorial no LinkedIn, mantendo uma narrativa visual orientada a padrões e contexto.

FICHA TÉCNICA

Tipo de análise
Análise de dados · Visualização · Data storytelling
Fonte de dados
Dados públicos da AENA
Período analisado
2024 e 2025
Unidade de análise
Passageiros aéreos associados aos aeroportos das Baleares
Território
Palma de Mallorca · Ibiza · Menorca
Variáveis principais
Passageiros, aeroportos, países, cidades, companhias aéreas, meses e sazonalidade
Eixo de análise
Procura aérea, sazonalidade, conectividade internacional e distribuição territorial do tráfego nas Baleares
Tratamento aplicado
Limpeza de dados, agregação temporal, comparação entre épocas e análise por aeroportos, países, cidades e companhias aéreas
Ferramentas
Python · Pandas · Plotly · GitHub
Resultado do projeto
Notebook analítico, gráficos e publicação no LinkedIn
Estado
