Progetto 08 · Machine Learning

Modello Machine Learning · Frode con K-means

✅ pubblicato

Clustering non supervisionato con K-means per la rilevazione di frodi con carte di credito.

CONTESTO E OBIETTIVO

Esplorare se una tecnica non supervisionata può separare comportamenti transazionali compatibili con pattern di frode.

DATI E DIAGNOSI

  • Si usano variabili transazionali per costruire gruppi di comportamento.
  • Si applica K-means per segmentare osservazioni senza usare un’etichetta precedente.
  • Si leggono i profili dei cluster per identificare segmenti con segnali atipici.

CONSEGNA E APPRENDIMENTO

La consegna confronta un’implementazione in SPSS Modeler e una versione in Python, mostrando il valore del clustering come strumento esplorativo per la frode.

SCHEDA TECNICA

Tipo di analisi
Machine Learning · Clustering · Rilevamento frodi
Fonte dei dati
Dataset di operazioni transazionali
Unità di analisi
Operazioni registrate nel dataset di frode
Variabili principali
Importo, comportamento dell’operazione, variabili transazionali, variabili derivate e segnali associati a pattern atipici
Asse di analisi
Segmentazione delle operazioni tramite K-means per identificare gruppi di comportamento e possibili pattern di frode
Trattamento applicato
Preparazione dei dati, pulizia delle variabili, scaling, segmentazione non supervisionata, analisi dei cluster e interpretazione dei profili
Strumenti
Python · Pandas · Scikit-learn · SPSS · GitHub
Output del progetto
Notebook di modellazione, grafici, segmentazione delle operazioni e documentazione su GitHub
