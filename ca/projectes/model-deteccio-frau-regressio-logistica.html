Projecte 09 · aprenentatge automàtic

Model d'aprenentatge automàtic · Frau amb regressió logística

✅ publicat

Anàlisi de transaccions amb targetes de crèdit per estimar la probabilitat de frau mitjançant regressió logística. El projecte utilitza informació d'operacions ja classificades per entrenar un model que identifica indicis associats al risc i permet analitzar les prediccions.

CONTEXT I OBJECTIU

El projecte utilitza registres d'operacions amb targeta de crèdit per estudiar quines característiques apareixen més sovint en les operacions associades a frau. Cada transacció conté dades que descriuen l'operació i una classificació que indica si es va registrar com a legítima o fraudulenta. Aquesta informació permet entrenar un model amb exemples coneguts i aplicar-lo després a altres transaccions.

L'objectiu és estimar la probabilitat de frau de cada operació i reconèixer quines variables contribueixen a aquesta estimació. La regressió logística permet abordar totes dues tasques: classifica les transaccions i permet interpretar la relació entre les característiques i el resultat previst.

MODEL I AVALUACIÓ

PREPARACIÓ DE LES DADES

Primer es revisen les variables del conjunt de transaccions i s'organitza la informació que utilitzarà el model. La preparació inclou la neteja de dades, la preparació de variables i l'equilibratge de classes, una consideració important quan els casos de frau són molt menys freqüents que les compres legítimes.

Aquesta preparació deixa les dades a punt per entrenar i avaluar el model. Les variables seleccionades descriuen cada operació, mentre que la classificació coneguda de frau serveix de referència perquè el model aprengui a distingir tots dos tipus de casos.

CLASSIFICACIÓ AMB REGRESSIÓ LOGÍSTICA

La regressió logística combina les característiques de cada transacció i estima una probabilitat de frau entre 0 i 1. Cada variable aporta informació al càlcul mitjançant un coeficient que el model ajusta durant l'entrenament. La funció logística converteix aquesta combinació en una probabilitat per a cada operació.

PROBABILITAT ESTIMADA DE FRAU
p(x)=\frac{1}{1+e^{-(\beta_0+\sum_{j=1}^{k}\beta_jx_j)}}

p(x) és la probabilitat estimada de frau. Les x representen característiques de la transacció; els coeficients beta reflecteixen l'aportació apresa de cada variable.

Els coeficients permeten analitzar com es relaciona cada característica amb la probabilitat estimada, tenint en compte les altres variables. Així es poden reconèixer els indicis associats a un risc més alt o més baix dins de les transaccions analitzades.

AVALUACIÓ DE LES PREDICCIONS

L'avaluació compara les prediccions amb la classificació coneguda de les operacions. Per decidir quines transaccions es marquen com a possibles fraus, la probabilitat estimada es compara amb un llindar de decisió. Aquest valor influeix en quants fraus es detecten i quantes compres legítimes generen alertes per revisar-les.

LLINDAR PER CLASSIFICAR TRANSACCIONS
\hat{y}=\begin{cases}1&\text{si }p(x)\geq t\\0&\text{si }p(x)<t\end{cases}

En aquesta regla general, 1 identifica una alerta de possible frau i 0 una operació classificada com a legítima. t és el llindar de decisió, el valor específic del qual es pot triar segons el criteri d'avaluació.

El projecte implementa el procés de modelització a SPSS Modeler i inclou una altra implementació en Python. Les mètriques i els gràfics d'avaluació permeten valorar el rendiment del model i analitzar els indicis associats al frau des de totes dues eines.

LLIURAMENT I APRENENTATGE

El treball presenta un model supervisat de regressió logística aplicat a operacions amb targetes de crèdit, juntament amb la preparació de variables, les prediccions i els resultats d'avaluació. La combinació de SPSS Modeler i Python permet seguir el procediment i revisar l'aportació de les variables a la classificació.

En incorporar transaccions noves amb les mateixes variables, el model es pot utilitzar per generar estimacions i comparar-les després amb els casos confirmats. Aquesta comparació permet comprovar si manté la capacitat de detecció i decidir quan convé actualitzar l'entrenament.
