Projecte 10 · aprenentatge automàtic

Model d'aprenentatge automàtic · Frau amb DBSCAN

✅ publicat

Anàlisi de transaccions amb targetes de crèdit per reconèixer patrons de comportament i detectar operacions atípiques. El projecte utilitza DBSCAN, un algorisme d'aprenentatge no supervisat que forma grups segons la densitat dels registres i identifica transaccions aïllades.

CONTEXT I OBJECTIU

El projecte treballa amb registres d'operacions fetes amb targetes de crèdit i analitza les característiques de cada transacció. A partir d'aquesta informació, identifica comportaments habituals, analitza com s'agrupen operacions semblants i detecta casos que es diferencien de la resta.

Per estudiar aquestes diferències s'utilitza DBSCAN, un mètode d'aprenentatge automàtic que agrupa operacions segons la semblança entre les característiques. El procediment reconeix concentracions de transaccions semblants i en destaca d'altres que queden aïllades.

L'anàlisi vol entendre aquests comportaments i identificar operacions atípiques per revisar-les amb més detall. Cada cas es pot avaluar després amb més informació del context de la transacció per determinar si requereix una investigació específica.

MODEL I ANÀLISI

PREPARACIÓ DE LES OPERACIONS

El treball utilitza les variables registrades a les transaccions, com ara l'import i altres característiques de cada operació. Es revisa la qualitat de les dades i es preparen les variables que permeten comparar els registres amb criteris coherents.

La comparació es basa en la semblança entre les operacions. Per considerar variables expressades en intervals numèrics diferents, el projecte n'ajusta les escales abans d'identificar els grups.

IDENTIFICACIÓ DE GRUPS AMB DBSCAN

DBSCAN identifica àrees on es concentren operacions amb característiques semblants i forma grups a partir d'aquestes concentracions. Per reconèixer-les, considera quins registres són prou propers entre si i quantes operacions similars hi ha al voltant de cadascun. Així, l'agrupament sorgeix de la distribució observada a les dades.

El resultat permet distingir tres situacions:

  • Operacions de nucli: estan envoltades de diversos registres semblants i ajuden a formar els grups.
  • Operacions de vora: són a prop d'un grup de transaccions semblants.
  • Operacions aïllades: queden fora dels grups identificats i reben l'etiqueta -1.

ANÀLISI DE LES OPERACIONS ATÍPIQUES

Els gràfics mostren com es distribueixen les operacions i quines característiques comparteixen els registres de cada grup. També permeten comparar aquests grups amb els casos aïllats i ajuden a reconèixer comportaments que mereixen una revisió més detallada.

L'etiqueta -1 assenyala una operació atípica segons els criteris utilitzats en l'anàlisi. L'import i les altres característiques es poden estudiar juntament amb informació addicional per valorar si és una compra poc habitual o una situació que requereix investigació.

LLIURAMENT I APRENENTATGE

El projecte inclou un quadern de Python amb la preparació de les dades, l'agrupament mitjançant DBSCAN i els gràfics per explorar-ne els resultats. Aquest material permet analitzar els grups d'operacions i seleccionar operacions atípiques per revisar-les posteriorment.

Quan s'incorporen transaccions noves, el procediment es pot repetir per observar com canvien els grups i quins casos apareixen com a atípics a les dades actualitzades. Mantenir els mateixos criteris de preparació facilita la comparació entre totes dues anàlisis.
