Projecte 08 · aprenentatge automàtic

Model d'aprenentatge automàtic · Frau amb K-means

✅ publicat

Agrupament no supervisat amb K-means per detectar frau amb targetes de crèdit.

CONTEXT I OBJECTIU

Explorar si una tècnica no supervisada pot separar comportaments transaccionals compatibles amb patrons de frau.

DADES I DIAGNÒSTIC

  • Ús de variables transaccionals per construir grups de comportament.
  • Aplicació de K-means per segmentar observacions sense utilitzar una etiqueta prèvia.
  • Lectura dels perfils dels grups per identificar segments amb indicis atípics.

LLIURAMENT I APRENENTATGE

La comparació de les versions en SPSS Modeler i Python mostra com l’agrupament de transaccions pot ajudar a explorar possibles patrons de frau.

FITXA TÈCNICA

Tipus d'anàlisi
Aprenentatge automàtic · Agrupament · Detecció de frau
Font de dades
Conjunt de dades d'operacions transaccionals
Unitat d'anàlisi
Operacions registrades al conjunt de dades de frau
Variables principals
Import, comportament de l'operació, variables transaccionals, variables derivades i indicis associats a patrons atípics
Eix de l'anàlisi
Segmentació d'operacions mitjançant K-means per identificar grups de comportament i possibles patrons de frau
Tractament aplicat
Preparació de dades, neteja de variables, escalat, segmentació no supervisada, anàlisi de grups i interpretació de perfils
Eines
Python · Pandas · Scikit-learn · SPSS · GitHub
Resultat del projecte
Quadern de modelització, gràfics, segmentació d'operacions i documentació a GitHub
