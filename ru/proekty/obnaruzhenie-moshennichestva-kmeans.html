Проект 08 · Машинное обучение

Модель машинного обучения · Выявление мошенничества методом K-средних

✅ опубликовано

Кластеризация без учителя методом K-средних для выявления мошенничества с кредитными картами.

КОНТЕКСТ И ЦЕЛЬ

Изучить, способен ли метод обучения без учителя выделить поведение транзакций, соответствующее признакам мошенничества.

ДАННЫЕ И ДИАГНОСТИКА

  • Использование транзакционных переменных для построения поведенческих групп.
  • Применение K-средних для сегментирования наблюдений без использования предварительной метки.
  • Чтение профилей кластеров для выявления сегментов с нетипичными сигналами.

РЕЗУЛЬТАТЫ И ВЫВОДЫ

Сравнение двух реализаций, в SPSS Modeler и на Python, показывает, как кластерный анализ помогает исследовать возможные схемы мошенничества.

ТЕХНИЧЕСКИЙ ЛИСТ

Тип анализа
Машинное обучение · Кластеризация · Обнаружение мошенничества
Источник данных
Набор данных транзакционных операций
Единица анализа
Операции, зафиксированные в наборе данных о мошенничестве
Основные переменные
Сумма, поведение операции, транзакционные переменные, производные переменные и сигналы, связанные с нетипичными шаблонами.
Ось анализа
Сегментация операций с использованием K-средств для выявления поведенческих групп и возможных моделей мошенничества
Примененная обработка
Подготовка данных, очистка переменных, масштабирование, неконтролируемая сегментация, кластерный анализ и интерпретация профиля.
Инструменты
