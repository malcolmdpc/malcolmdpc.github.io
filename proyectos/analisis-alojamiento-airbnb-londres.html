Proyecto 02 · Analítica de datos

Análisis de Airbnb en Londres

✅ publicado datos: 2025

Análisis exploratorio de Airbnb en Londres para comparar precios, tipos de alojamiento, disponibilidad, estancias mínimas y diferencias entre barrios.

CONTEXTO Y OBJETIVO

Explorar las variaciones de precio de los alojamientos Airbnb en Londres a partir del tipo de alojamiento, el barrio, la disponibilidad y la estancia mínima.

DATOS Y DIAGNÓSTICO

  • Uso de datos públicos de Inside Airbnb como fuente principal.
  • Limpieza y aplicación de filtros de calidad sobre precio, reseñas recientes, estancia mínima y disponibilidad para construir una base analítica consistente.
  • Construcción de indicadores y visuales para comparar precios por tipo de alojamiento, barrio, estancia mínima y disponibilidad anual.

ENTREGA Y APRENDIZAJE

El proyecto queda presentado como análisis reproducible en GitHub y como pieza editorial en LinkedIn, con una lectura visual centrada en la estructura de precios y las diferencias entre segmentos del mercado.

FICHA TÉCNICA

Tipo de análisis
Analítica de datos · Visualización · Data storytelling
Fuente de datos
Inside Airbnb · Londres
Período analizado
Septiembre 2025
Unidad de análisis
Alojamientos publicados en Airbnb dentro de Londres
Variables principales
Precio, tipo de habitación, barrio, disponibilidad anual, noches mínimas, reseñas, actividad reciente y cantidad de anuncios por anfitrión
Eje de análisis
Precios y diferencias por tipo de alojamiento, barrio, disponibilidad anual y estancia mínima
Tratamiento aplicado
Limpieza de datos, filtros de calidad, análisis descriptivo y comparación por segmentos
Herramientas
Python · Pandas · Plotly · GitHub
Salida del proyecto
Notebook analítico, gráficos y documentación en GitHub
Estado
Publicado
