Proyecto 16 · Machine Learning

Redes Neuronales · Daños en Eventos Meteo

⚠️ en desarrollodatos:2025

Modelo de clasificación aplicado a datos de NOAA Storm Events para estimar la probabilidad de daño económico registrado en eventos meteorológicos. El proyecto trabaja con información de 2010 a 2025, compara una regresión logística y una red neuronal, y evalúa su desempeño sobre años posteriores a los utilizados para el entrenamiento.

CONTEXTO Y OBJETIVO

El proyecto utiliza 1.037.691 eventos meteorológicos registrados por NOAA Storm Events entre 2010 y 2025. Cada registro incluye información sobre el fenómeno observado, la fecha y la ubicación, además de características meteorológicas y los importes de daños en propiedades y cultivos cuando fueron informados.

A partir de estos datos se definió una variable objetivo que identifica los eventos con daño económico registrado. El análisis estima la probabilidad de ese resultado utilizando información temporal, territorial y meteorológica de cada evento. Para que la predicción dependa de esas características, los importes de daños y otras variables que revelan directamente la respuesta quedaron fuera del conjunto de predictores.

Se compararon dos modelos de clasificación supervisada. La regresión logística permite establecer una referencia estadística mediante coeficientes asociados a las variables; la red neuronal incorpora mayor flexibilidad para aprender relaciones entre ellas. Los modelos se entrenaron con datos de 2010 a 2021, se validaron con 2022 y 2023 y se evaluaron finalmente con eventos de 2024 y 2025. Esta división temporal permite medir su desempeño con registros más recientes que los utilizados para ajustar cada modelo.

MODELO Y VALIDACIÓN

Preparación de datos y definición del daño registrado

Primero se descargaron e integraron los archivos anuales de NOAA Storm Events en una sola base. Se revisaron los nombres y tipos de columnas, los valores faltantes y la consistencia de los datos entre años antes de preparar las variables para el modelo.

Los daños de propiedades y cultivos aparecen en los archivos con distintas unidades, por ejemplo, miles o millones. Se transformaron a importes numéricos comparables y se sumaron para construir la variable que indica si cada evento tiene daños económicos registrados.

VARIABLE OBJETIVO · DAÑO ECONÓMICO REGISTRADO
y_i=\mathbb{1}\left(D_{\mathrm{prop},i}+D_{\mathrm{cult},i}>0\right)

El indicador vale 1 cuando la suma de los daños materiales y agrícolas registrados es mayor que cero, y vale 0 en los demás casos. Para construirlo, los importes sin monto informado se trataron como cero. Por eso, el modelo identifica daños registrados en NOAA, que no necesariamente representan todos los daños que pudieron ocurrir.

Para realizar las predicciones se utilizaron 19 variables de origen: diez numéricas y nueve categóricas. Entre ellas hay datos sobre fechas, lugares, tipos de evento, magnitudes y coordenadas. También se crearon indicadores para señalar información faltante. Los importes de daños y las columnas que revelaban directamente el resultado quedaron fuera de los predictores, para que el modelo aprendiera a partir de las características del evento.

División temporal y preparación de variables

Los registros se separaron cronológicamente en tres conjuntos: 2010-2021 para entrenamiento, 2022-2023 para validación y 2024-2025 para la prueba final. El primer período se utilizó para estimar los modelos; el segundo, para seguir su desempeño durante el desarrollo; y el tercero se reservó para la comparación final sobre datos posteriores.

Antes de entrenar los modelos se aplicó un preprocesamiento común. En las variables numéricas, los faltantes se completaron con la mediana del conjunto de entrenamiento y los valores se estandarizaron para trabajar con escalas comparables. Las variables categóricas se transformaron mediante one-hot encoding, que crea columnas indicadoras para las categorías observadas. El preprocesamiento se ajustó con los datos de entrenamiento y después se aplicó a validación y prueba sin recalcular sus parámetros.

Regresión logística como modelo de referencia

La regresión logística fue el modelo de referencia del análisis. Durante el entrenamiento estima un coeficiente para cada variable transformada y combina esos aportes en una puntuación que resume la tendencia del evento a presentar daños registrados. El signo de cada coeficiente indica si una variable aumenta o reduce esa puntuación, manteniendo constantes las demás; su magnitud refleja el peso de esa contribución en la escala del modelo. La función sigmoide transforma el resultado en una probabilidad entre 0 y 1.

PROBABILIDAD ESTIMADA CON REGRESIÓN LOGÍSTICA
\hat{p}_i=\frac{1}{1+e^{-(\beta_0+\sum_j\beta_jx_{ij})}}

En la ecuación, las x representan las variables después del preprocesamiento y las β son los coeficientes estimados a partir de los datos de entrenamiento. La sigmoide transforma la combinación lineal en una probabilidad de daño económico registrado entre 0 y 1.

El entrenamiento incluye regularización L2 para moderar los coeficientes demasiado grandes y favorecer una estimación más estable cuando se trabaja con muchas variables transformadas. La regresión logística proporciona así un punto de comparación concreto: sus probabilidades, aciertos y errores se contrastan con los de la red neuronal sobre los mismos períodos, para evaluar cuánto aporta la mayor flexibilidad de esta última.

Red neuronal y comparación de resultados

Con las mismas variables ya preparadas se entrenó una red neuronal con capas densas. A diferencia de la regresión logística, la red combina las señales en varias etapas mediante pesos que aprende durante el entrenamiento. Las activaciones ReLU le permiten captar relaciones no lineales; el dropout ayuda a reducir el sobreajuste, y la capa final utiliza una sigmoide para expresar la predicción como una probabilidad de daño registrado.

TRANSFORMACIÓN EN LAS CAPAS OCULTAS
h^{(l)}=\mathrm{ReLU}\left(W^{(l)}h^{(l-1)}+b^{(l)}\right)

En cada capa, los pesos W y los sesgos b transforman la información recibida. La función ReLU permite que la red aprenda relaciones que no se describen con una combinación puramente lineal.

PROBABILIDAD DE LA RED NEURONAL
\hat{p}_i=\sigma\left(w^\top h_i+b\right)

La capa final aplica la función sigmoide σ a la información aprendida por la red y devuelve una probabilidad de daño registrado para cada evento.

Para entrenar la red se utilizó Adam, que ajusta los pesos a partir de los errores del modelo, y entropía cruzada binaria para medir la diferencia entre las probabilidades previstas y los resultados observados. El seguimiento de la validación permitió ajustar el ritmo de aprendizaje y detener el entrenamiento cuando dejó de mejorar, para limitar el sobreajuste.

PÉRDIDA · ENTROPÍA CRUZADA BINARIA
\mathcal{L}=-\frac{1}{n}\sum_{i=1}^{n}\left[y_i\log(\hat{p}_i)+(1-y_i)\log(1-\hat{p}_i)\right]

La entropía cruzada compara el resultado observado y con la probabilidad estimada p̂. Cuanto menor es su valor, mejor se ajustan las probabilidades a los resultados reales.

La comparación final se realizó con ROC AUC y PR AUC, que evalúan qué tan bien separa cada modelo los eventos con daños registrados de los demás. PR AUC es especialmente importante porque los eventos con daño positivo son menos frecuentes. También se calcularon precisión, recall, F1 y matrices de confusión para revisar cuántos casos positivos detecta cada modelo y cuántas alertas resultan correctas.

PRECISIÓN Y RECUPERACIÓN DE EVENTOS CON DAÑO
\mathrm{Precision}=\frac{VP}{VP+FP}
\mathrm{Recall}=\frac{VP}{VP+FN}

VP son los casos con daño que el modelo detectó correctamente; FP, las alertas positivas de eventos sin daño registrado; y FN, los casos con daño que el modelo no identificó. La precisión mide qué proporción de las alertas positivas fue correcta y el recall, qué proporción de los eventos con daño logró detectar.

ENTREGA Y APRENDIZAJE

En la prueba final con eventos de 2024-2025, la red neuronal obtuvo un ROC AUC de 0,9324 y un PR AUC de 0,8004. La regresión logística alcanzó 0,8961 y 0,6691, respectivamente. La red neuronal distinguió mejor los eventos con daños registrados, con una ventaja especialmente clara en PR AUC.

Al observar sólo los eventos con daño registrado, la red neuronal alcanzó una precisión de 0,7942, un recall de 0,6243 y un F1 de 0,6991. La regresión logística obtuvo 0,7580, 0,5023 y 0,6042. En términos prácticos, la red neuronal identificó una proporción mayor de esos eventos y mantuvo una precisión superior en sus alertas positivas.

MÉTRICA F1 · EQUILIBRIO ENTRE PRECISIÓN Y RECALL
F_1=2\,\frac{\mathrm{Precision}\cdot\mathrm{Recall}}{\mathrm{Precision}+\mathrm{Recall}}

F1 combina precisión y recall en un solo indicador. Sirve para comparar modelos cuando importa detectar la clase positiva y, al mismo tiempo, evitar demasiadas alertas incorrectas.

La comparación entrega probabilidades estimadas por evento, predicciones de ambos modelos, matrices de confusión, métricas comparativas y gráficos del entrenamiento. Se conservaron el preprocesamiento y los modelos para aplicar el mismo criterio a nuevos registros con las mismas variables. Cuando se incorporen datos de años posteriores, sus predicciones podrán compararse con los daños registrados para comprobar si el rendimiento se mantiene o si conviene volver a entrenar.
