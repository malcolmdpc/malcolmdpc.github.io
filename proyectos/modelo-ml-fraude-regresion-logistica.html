Proyecto 09 · Machine Learning

Modelo Machine Learning · Fraude con Regresión Logística

✅ publicado

Análisis de transacciones con tarjetas de crédito para estimar la probabilidad de fraude mediante regresión logística. El proyecto utiliza información de operaciones ya clasificadas para entrenar un modelo que identifica señales asociadas al riesgo y permite analizar sus predicciones.

CONTEXTO Y OBJETIVO

El proyecto utiliza registros de operaciones con tarjeta de crédito para estudiar qué características aparecen con mayor frecuencia en las operaciones asociadas a fraude. Cada transacción contiene datos que describen la operación y una clasificación que indica si fue registrada como legítima o fraudulenta. Esa información permite entrenar un modelo con ejemplos conocidos y aplicarlo después a otras transacciones.

El objetivo es estimar la probabilidad de fraude de cada operación y reconocer qué variables contribuyen a esa estimación. La regresión logística permite abordar ambas tareas: clasifica las transacciones y permite interpretar la relación entre sus características y el resultado previsto.

MODELO Y EVALUACIÓN

PREPARACIÓN DE LOS DATOS

Primero se revisan las variables del conjunto de transacciones y se organiza la información que utilizará el modelo. La preparación incluye la limpieza de datos, la preparación de variables y el balanceo de clases, una consideración importante cuando los casos de fraude aparecen con una frecuencia mucho menor que las compras legítimas.

Esta preparación deja los datos listos para entrenar y evaluar el modelo. Las variables seleccionadas describen cada operación, mientras que la clasificación conocida de fraude funciona como referencia para que el modelo aprenda a distinguir ambos tipos de casos.

CLASIFICACIÓN CON REGRESIÓN LOGÍSTICA

La regresión logística combina las características de cada transacción y estima una probabilidad de fraude entre 0 y 1. Cada variable aporta información al cálculo mediante un coeficiente que el modelo ajusta durante el entrenamiento. La función logística convierte esa combinación en una probabilidad para cada operación.

PROBABILIDAD ESTIMADA DE FRAUDE
p(x)=\frac{1}{1+e^{-(\beta_0+\sum_{j=1}^{k}\beta_jx_j)}}

p(x) es la probabilidad estimada de fraude. Las x representan características de la transacción; los coeficientes beta reflejan el aporte aprendido de cada variable.

Los coeficientes permiten analizar cómo se relaciona cada característica con la probabilidad estimada, teniendo en cuenta las demás variables. Así se pueden reconocer las señales asociadas a un mayor o menor riesgo dentro de las transacciones analizadas.

EVALUACIÓN DE LAS PREDICCIONES

La evaluación compara las predicciones con la clasificación conocida de las operaciones. Para decidir qué transacciones se marcan como posibles fraudes, la probabilidad estimada se compara con un umbral de decisión. Ese valor influye en cuántos fraudes se detectan y cuántas compras legítimas generan alertas para su revisión.

UMBRAL PARA CLASIFICAR TRANSACCIONES
\hat{y}=\begin{cases}1&\text{si }p(x)\geq t\\0&\text{si }p(x)<t\end{cases}

En esta regla general, 1 identifica una alerta de posible fraude y 0 una operación clasificada como legítima. t es el umbral de decisión, cuyo valor específico puede elegirse según el criterio de evaluación.

El proyecto implementa el proceso de modelado en SPSS Modeler y incluye otra implementación en Python. Las métricas y los gráficos de evaluación permiten evaluar el desempeño del modelo y analizar las señales asociadas al fraude desde las dos herramientas.

ENTREGA Y APRENDIZAJE

El trabajo presenta un modelo supervisado de regresión logística aplicado a operaciones con tarjetas de crédito, junto con la preparación de variables, las predicciones y los resultados de evaluación. La combinación de SPSS Modeler y Python permite seguir el procedimiento y revisar el aporte de las variables a la clasificación.

Al incorporar nuevas transacciones con las mismas variables, el modelo puede utilizarse para generar estimaciones y compararlas después con los casos confirmados. Esa comparación permite comprobar si mantiene su capacidad de detección y decidir cuándo conviene actualizar el entrenamiento.
